Card Receipt

Price a stack of cards straight from TCGplayer.

Find a card on TCGplayer, tap one button, and its Market Price, Listed Median and page link go onto a receipt. Adjust any price, add a note, then save, print or email it.

Add to receipt

On a computer, drag this button to your bookmarks bar. On a phone or tablet, copy the code below and follow the steps for your device.

Show the code to copy by hand

Set it up

Each device needs this once. Pick yours.

Install

  1. Show the bookmarks bar: Ctrl+Shift+B on Windows, Cmd+Shift+B on Mac.
  2. Drag the purple Add to receipt button onto the bar.
  3. If dragging doesn't work, copy the code, right-click the bar, choose Add page, name it Add to receipt and paste the code as the address.

Use

  1. Open a card's page on TCGplayer and pick the condition you want.
  2. Click Add to receipt in your bookmarks bar. The receipt opens on the right.
  3. Click Add this card. Search for the next card and repeat.

Install (Safari)

  1. Tap Copy the code above.
  2. Tap the Share button, then Add Bookmark. Name it Add to receipt and save.
  3. Open Bookmarks (the book icon), tap Edit, then tap Add to receipt.
  4. Delete the address, paste the code in its place and tap Done.

Use

  1. Open a card's page on TCGplayer and pick the condition you want.
  2. Open Bookmarks and tap Add to receipt. The receipt slides up.
  3. Tap Add this card. Tap the minimize button to search for the next card, then tap Add this card in the bar at the bottom.

Install (Chrome)

  1. Tap Copy the code above.
  2. Tap the menu (three dots), then the star to bookmark this page.
  3. Tap Edit on the message that appears. Name it addreceipt, replace the address with the code, and save.

Use

  1. Open a card's page on TCGplayer and pick the condition you want.
  2. Tap the address bar, type addreceipt, and tap the bookmark suggestion (the one with the star, not the search result).
  3. Tap Add this card. Tap the minimize button to search for the next card, then tap Add this card in the bar at the bottom.

Good to know

Tap Save to keep a receipt.

Saved receipts are listed under Saved receipts, newest first, and you can search them by customer or card. Tap Open to load one back into the receipt, change it, and tap Save again to update it.

Receipts stay on the device that made them.

The receipt you're working on and your saved receipts are kept in that browser on that device, so you can close the page and come back. Clearing the browser's website data for TCGplayer deletes them.

Prices are read from the page as it's shown.

Choose the right condition and printing on TCGplayer before adding, and let the prices finish loading.

Listed Median is the starting price.

Tap any other price on the card to use it, or type your own. Choose which prices appear (Market Price, Listed Median, Listing price, Most Recent Sale, Low and High Sale Price) under Prices and links. Anything different from Listed Median is marked as adjusted on screen, and your note prints on the receipt.

Email opens your own email app.

Tap Email and a message with the receipt is ready to send, addressed to the customer email under Shop and customer if you filled it in. Turn on Card links on receipt to include each card's TCGplayer page on both the printed and emailed receipt.

If prices stop being found, TCGplayer probably changed its page.

You can still type prices by hand while the button is updated.
