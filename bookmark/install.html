Card Receipt

Price a stack of cards straight from TCGplayer.

Find a card on TCGplayer, tap one button, and its Market Price, Listed Median and page link go onto a receipt. Scan cards from your own inventory too. Adjust any price, add a note, then save it, print it, email it as a PDF, or export it to a spreadsheet.

Add to receipt

On a computer, drag this button to your bookmarks bar. On a phone or tablet, copy the code below and follow the steps for your device.

Show the code to copy by hand

Set it up

Each device needs this once. Pick yours.

Install

  1. Show the bookmarks bar: Ctrl+Shift+B on Windows, Cmd+Shift+B on Mac.
  2. Drag the purple Add to receipt button onto the bar.
  3. If dragging doesn't work, copy the code, right-click the bar, choose Add page, name it Add to receipt and paste the code as the address.

Use

  1. Open a card's page on TCGplayer and pick the condition you want.
  2. Click Add to receipt in your bookmarks bar. The receipt opens on the right.
  3. Click Add this card. Search for the next card and repeat.

Install (Safari)

  1. Tap Copy the code above.
  2. Tap the Share button, then Add Bookmark. Name it Add to receipt and save.
  3. Open Bookmarks (the book icon), tap Edit, then tap Add to receipt.
  4. Delete the address, paste the code in its place and tap Done.

Use

  1. Open a card's page on TCGplayer and pick the condition you want.
  2. Open Bookmarks and tap Add to receipt. The receipt slides up.
  3. Tap Add this card. Tap the minimize button to search for the next card, then tap Add this card in the bar at the bottom.

Install (Chrome)

  1. Tap Copy the code above.
  2. Tap the menu (three dots), then the star to bookmark this page.
  3. Tap Edit on the message that appears. Name it addreceipt, replace the address with the code, and save.

Use

  1. Open a card's page on TCGplayer and pick the condition you want.
  2. Tap the address bar, type addreceipt, and tap the bookmark suggestion (the one with the star, not the search result).
  3. Tap Add this card. Tap the minimize button to search for the next card, then tap Add this card in the bar at the bottom.

Good to know

Tap Save to keep a receipt.

Each saved receipt gets a number, starting at #1001. Find them under Saved, search by customer, card or number, and tap Open to change one and save it again.

Build an inventory with barcodes.

Under Inventory, open a card on TCGplayer and tap Add this card to inventory, click New item, or import a CSV file (a TCGplayer seller export works). Scan an existing barcode label or let Card Receipt make one, then print labels.

Scan to add to a receipt.

Click the barcode box on the receipt and scan. A scanner that pairs by Bluetooth works on phones and tablets too. Saving a receipt takes those cards out of stock, and deleting it puts them back.

Listed Median is the starting price.

Tap any other price on a card to use it, or type your own. Under Prices and links, choose which prices show, turn on the average of the checked prices, and pick the starting price for new cards.

Put the receipt in any order.

Use the Sort menu for name, price or card number, or drag the dotted handle beside a card to move it by hand.

Export prints, emails or saves the receipt.

Tap Export to print, email it as a PDF, or save it as a PDF, a picture (PNG), a CSV file or an Excel file. The CSV and Excel files have the columns Item #, Item Name, Attribute, Size, Qty, Price, Ext Price and Tax Code, one row per card.

Emailing from a phone or tablet.

Email with PDF opens the share menu with the PDF attached. Choose Mail or your email app and add the customer's address. Where sharing isn't available, the PDF downloads and an email opens for you to attach it to.

Make it yours in Settings.

Tap the settings button to add your shop name and logo for receipts, pick a color (including hot pink, royal blue and dark red) or switch to dark mode, choose a label size, and back up everything to one file.

Everything stays on the device that made it.

Receipts, inventory and settings are kept in that browser on that device. Clearing the browser's website data for TCGplayer deletes them, so use Back up all data in Settings now and then. For a large inventory, the desktop app is the safer place to keep it.

Prices are read from the page as it's shown.

Choose the right condition and printing on TCGplayer before adding, and let the prices finish loading. If prices stop being found, TCGplayer probably changed its page. You can still type prices by hand.
