Card Receipt for Windows

1. Right-click the downloaded zip file and choose Extract All.
   Put the "Card Receipt" folder somewhere you'll keep it, like Documents.
2. Open the folder and double-click "Card Receipt.exe".
3. The first time, Windows may say "Windows protected your PC".
   Click "More info", then "Run anyway". You only need to do this once.
4. To make a desktop shortcut: right-click "Card Receipt.exe",
   choose Show more options, then Send to > Desktop (create shortcut).

Keep all the files in the folder together. The app needs them.

Saved receipts are kept on this computer. To find the file, press Alt to
show the menu, then choose Receipt > Show saved receipts file.
