Card Receipt for Windows 7 (32-bit)

This version is for older computers running Windows 7 Service Pack 1,
32-bit or 64-bit. It also works on Windows 8 and 8.1. If the computer
runs Windows 10 or 11, use Card-Receipt-Windows.zip instead.

Windows 7 no longer gets security updates, and this version uses an
older browser engine that no longer does either. It only opens
TCGplayer; other websites open in the computer's own browser. Avoid
signing in or paying for anything inside the app, and move to the
regular version when the shop gets a newer computer.

1. Right-click the downloaded zip file and choose Extract All.
   Put the "Card Receipt" folder somewhere you'll keep it, like Documents.
2. Open the folder and double-click "Card Receipt.exe".
3. If Windows shows "Open File - Security Warning", click Run.
   You only need to do this once.
4. To make a desktop shortcut: right-click "Card Receipt.exe" and
   choose Send to > Desktop (create shortcut).

Keep all the files in the folder together. The app needs them.

Saved receipts are kept on this computer. To find them, press Alt to
show the menu, then choose Receipt > Show data folder.
