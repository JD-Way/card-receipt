**Downloads** (under Assets below):
- **Card-Receipt-Windows.zip** for Windows 10 or 11 (64-bit)
- **Card-Receipt-Mac-AppleSilicon.zip** for Macs with an M1 chip or newer
- **Card-Receipt-Mac-Intel.zip** for Macs with an Intel processor (macOS 13 or newer for both Mac versions)

Each zip has a "Read me first" file with install steps. The first time you open the app, Windows or macOS shows a warning because the app isn't signed yet. The read-me explains how to get past it.

**What's new in 1.3**
- **Export button.** Print and Email are now in one Export menu, along with Save as PDF, Save as image (PNG), Save as CSV and Save as Excel (.xls).
- **Spreadsheet columns.** CSV and Excel files have Item #, Item Name, Attribute, Size, Qty, Price, Ext Price and Tax Code, one row per card.
- **Email with a PDF attached.** On Windows the default email program opens with the PDF attached; on Mac, Apple Mail or Outlook does. If that isn't possible, the PDF is saved and its folder opens so you can drag it in.
- **New colors.** Hot pink, royal blue and dark red, in light and dark mode.
- **Group by game removed.** It couldn't reliably tell which game a card is from. Sorting and dragging still work.

From 1.2: sorting and drag to rearrange. From 1.1: inventory with barcodes and labels, scan to add, average price, receipt numbers, shop logo and colors, and backups.

Your existing receipts carry over when you install this version.
