**Downloads** (under Assets below):
- **Card-Receipt-Windows.zip** for Windows 10 or 11 (64-bit)
- **Card-Receipt-Windows7-32bit.zip** for Windows 7 SP1, 8 or 8.1 (32-bit or 64-bit). It runs on an older engine that no longer gets security updates; see its read-me.
- **Card-Receipt-Mac-AppleSilicon.zip** for Macs with an M1 chip or newer
- **Card-Receipt-Mac-Intel.zip** for Macs with an Intel processor (macOS 13 or newer for both Mac versions)

Each zip has a "Read me first" file with install steps. The first time you open the app, Windows or macOS shows a warning because the app isn't signed yet. The read-me explains how to get past it.

**What's new in 1.4**
- **Price rounding.** Picked prices round to shop-friendly amounts. By default .01 to .30 rounds to .25 and .31 to .49 rounds to .50. Set your own rules in Settings > Rounding, or turn it off. Prices you type aren't rounded.
- **Simple view.** One tap shows just each card's name and receipt price. Drag to reorder still works.
- **Hide price details on the receipt.** Leaves the TCGplayer reference prices off the printed, emailed and saved receipt.
- **Phones:** the browser panel now fills the screen and only the card list scrolls.
- **Windows 7 version** (32-bit).

From 1.3: the Export menu (PDF, PNG, CSV, Excel, email with PDF) and new colors. From 1.2: sorting and drag to rearrange. From 1.1: inventory with barcodes and labels, scan to add, average price, receipt numbers, shop logo and colors, and backups.

Your existing receipts carry over when you install this version.
